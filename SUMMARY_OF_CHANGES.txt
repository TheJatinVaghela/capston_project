STEP 5: Restart backend
  └─ Press Ctrl+C in Terminal
  └─ Run: python app.py

  └─ Ask chatbot a question

🤖 HOW 3-TIER SYSTEM COMBINES ANSWERS
═════════════════════════════════════════════════════════════════════════════

QUESTION: "Can I return something after 2 weeks AND ship to Canada?"

SYSTEM PROCESS:

TIER 1 - FAQ CHECK (instant):
  ├─ Find FAQ #2: "How do I return an item?" ✓ MATCH
  ├─ Find FAQ #6: "Do you ship internationally?" ✓ MATCH
  └─ Extract both answers

COMBINE ANSWERS:
  ├─ Format #1: "RETURNS: You have 30 days..."
  ├─ Format #2: "CANADA SHIPPING: Yes, we ship to Canada..."
  └─ Merge into single response

RESULT TO CUSTOMER:
  "Great questions! Here's what you need to know:
  
  ✓ RETURNS: You have 30 days to return unused items...
  
  ✓ CANADA SHIPPING: Yes, we ship to Canada with tracking..."
  
  Badge: 📚 FAQ (from database)
  Time: < 0.1 seconds ⚡

✅ WHAT'S BEEN FIXED
═════════════════════════════════════════════════════════════════════════════

MODEL SWITCHING BUG - FIXED!

BEFORE (BROKEN):
  • System only used Mistral model
  • Model dropdown had no effect
  • Other models ignored
  • Reason: Single global instance created with Mistral at startup

AFTER (FIXED):
  • Each model (Mistral/Llama2/Neural-Chat) works perfectly
  • Switch models instantly in frontend
  • Backend creates/caches separate instance per model
  • Respects model parameter in API requests

HOW IT WAS FIXED:
  File: backend/chatbot.py (lines 348-382)
  
  Changed from:
    _chatbot_instance = None  # Single instance
  
  To:
    _chatbot_instances = {}   # Dictionary of instances
  
  Now:
    if model not in _chatbot_instances:
      _chatbot_instances[model] = OllamaAIChatbot(model=model)
    return _chatbot_instances[model]
  
  Result: Each model gets its own cached instance!

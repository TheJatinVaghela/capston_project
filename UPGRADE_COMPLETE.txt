🤖 HOW IT WORKS - HYBRID 3-TIER SYSTEM
═══════════════════════════════════════════════════════════════════════════════

TIER 1: FAQ DATABASE (0.1 seconds) ⚡
  Purpose: Instant answers to common questions
  Speed: ~0.1 seconds
  Accuracy: 100%
  Examples: "What's shipping cost?", "How do I return?"
  Technology: Hash-based lookup

TIER 2: PATTERN MATCHING (0.2 seconds) 🔍
  Purpose: Intent recognition for standard queries
  Speed: ~0.2 seconds
  Accuracy: 85-90%
  Examples: "Hello", "Thank you", "Goodbye"
  Technology: NLTK preprocessing + token matching

TIER 3: OLLAMA AI (1-3 seconds) 🤖
  Purpose: Intelligent reasoning for complex queries
  Speed: 1-3 seconds (first), 0.5-1s (cached)
  Accuracy: 80-95% (depends on model)
  Examples: "What laptop for gaming?", "Shipping to Canada?"
  Technology: Mistral, Llama2, or Neural-Chat local LLM

Response Flow:
  Question → FAQ Check → Pattern Check → Ollama AI → Answer

GET /
  Health check, returns features list

POST /chat
  Request: {
    "message": "user query",
    "use_ai": null,        // null=auto, true=AI, false=FAQ-only

  List available Ollama models

GET /logs
  All chat messages with model used

DELETE /logs
  Clear all chat history

GET /stats
  Intent distribution + model usage

GET /business-info
  Company info, products, policies

❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Q: Backend says "Ollama not running"
A: Open terminal and run: ollama serve
   Keep this window open while using chatbot

Q: "Model not found" error
A: Pull the model: ollama pull mistral
   (or llama2, neural-chat)

Q: Very slow responses (10+ seconds)
A: - Restart ollama serve
   - First query loads model (normal, takes 1-2s)
   - Check system RAM
   - Try FAQ-only mode (uncheck AI toggle)

Q: Connection refused error
A: - Check ollama serve is running
   - Verify nothing is using ports 11434 or 5000
   - Restart both services

Q: Backend starts but no Ollama connection
A: - Make sure ollama serve is running first
   - Check: ollama pull mistral works
   - Verify port 11434 is free

Q: Model runs out of RAM
A: - Use FAQ-only mode
   - Restart ollama serve
   - Try smaller model (Mistral uses less RAM)
   - Close other applications

See: OLLAMA_SETUP.txt for detailed troubleshooting!

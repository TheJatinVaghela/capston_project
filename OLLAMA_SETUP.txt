================================================================================
OLLAMA SETUP GUIDE - AI Customer Service Chatbot
================================================================================

Your chatbot now uses Ollama for intelligent AI-powered responses!

What is Ollama?
- Local AI model runner (no API keys, no cloud dependency)
- Supports Mistral, Llama2, Neural-Chat, and more
- Privacy-focused (everything runs on your machine)
- Fast inference (sub-second responses)

================================================================================
STEP 1: INSTALL OLLAMA
================================================================================

Windows:
  1. Download from: https://ollama.ai/download
  2. Run the installer
  3. Accept default installation
  4. Ollama will start automatically

macOS:
  1. Download from: https://ollama.ai/download
  2. Open the .dmg file
  3. Drag Ollama to Applications
  4. Launch Ollama from Applications

Linux:
  curl https://ollama.ai/install.sh | sh

Verify installation:
  ollama --version
  
================================================================================
STEP 2: PULL AI MODELS
================================================================================

Recommended models (choose at least one):

Option 1: Mistral (FASTEST ⚡)
  ollama pull mistral
  Size: ~4GB
  Speed: Fastest responses
  Quality: Very good

Option 2: Llama2 (BALANCED ⚖️)
  ollama pull llama2
  Size: ~3.8GB
  Speed: Medium
  Quality: Excellent

Option 3: Neural-Chat (BEST FOR CHAT 💬)
  ollama pull neural-chat
  Size: ~3.8GB
  Speed: Medium
  Quality: Optimized for conversations

Install all (recommended):
  ollama pull mistral
  ollama pull llama2
  ollama pull neural-chat

Each model downloads once (~4GB each). Takes 5-15 minutes on first pull.

================================================================================
STEP 3: START OLLAMA SERVER
================================================================================

Open Command Prompt or Terminal and run:
  ollama serve

You should see:
  2024/01/15 10:30:00 Listening on 127.0.0.1:11434

Keep this window open while using the chatbot!

================================================================================
STEP 4: START CHATBOT
================================================================================

In another terminal/command prompt:
  cd customer-service-chatbot\backend
  pip install -r requirements.txt
  python app.py

You should see:
  ============================================================
  AI Customer Service Chatbot with Ollama Integration
  ============================================================
  Server: http://127.0.0.1:5000
  ...
  Make sure Ollama is running:
    ollama serve

If you see this, Ollama connection was successful!

================================================================================
STEP 5: OPEN FRONTEND
================================================================================

Open your browser and go to:
  file:///D:/customer-service-chatbot/frontend/index.html

Or drag customer-service-chatbot/frontend/index.html to your browser.

TOGGLE AI MODE
================================================================================

Use the checkbox: "AI Mode: Auto"

✓ Checked (Auto):
  - FAQ database for common questions
  - Ollama AI for unusual queries
  - Recommended for balanced performance

✗ Unchecked (FAQ Only):
  - Only uses FAQ database

================================================================================
TROUBLESHOOTING OLLAMA
================================================================================

Issue: "Ollama not running. Start with: ollama serve"
Solution:
  1. Open Command Prompt or Terminal
  2. Type: ollama serve
  3. Wait for "Listening on 127.0.0.1:11434"
  4. Keep this window open

Issue: "Model not found"
Solution:
  1. Open another terminal (keep ollama serve running)
  2. Type: ollama pull mistral (or llama2, neural-chat)
  3. Wait for download to complete
  4. Restart chatbot

Issue: Very slow responses (10+ seconds)
Solution:
  1. Your GPU might not be supported
  2. Try a smaller model: ollama pull neural-chat
  3. Or use CPU mode (slower but works everywhere)
  4. Check system resources (RAM usage)

Issue: "Connection refused" on backend
Solution:
  1. Make sure: ollama serve is running
  2. Check Ollama is on http://localhost:11434
  3. Verify port 11434 isn''t blocked by firewall
  4. Try: ollama serve --host 0.0.0.0

Issue: Out of memory error
Solution:
  1. Close other applications
  2. Use FAQ-only mode (uncheck AI Mode)
  3. Restart Ollama: ollama serve
  4. Try smaller model: mistral uses less RAM

================================================================================
HARDWARE REQUIREMENTS
================================================================================

Minimum (CPU only):
  • 8GB RAM
  • 15GB disk space (for models)
  • Any processor
  • Speed: ~1-3 seconds per response

Recommended (GPU acceleration):
  • 16GB+ RAM
  • 15GB disk space
  • NVIDIA GPU (RTX 3060+) or Apple Silicon
  • Speed: ~0.5-1 second per response

GPU Support:
  • NVIDIA: Automatic (CUDA enabled)
  • Apple Silicon (M1/M2): Automatic
  • AMD: Experimental (ROCm)
  • Intel GPU: Not yet supported

================================================================================
PERFORMANCE TIPS
================================================================================

1. Use Mistral for speed:
   - 20-30% faster than Llama2
   - Good quality for most queries
   - Best for high-volume testing

2. Use Llama2 for accuracy:
   - More accurate on complex questions
   - Slightly slower
   - Better for business-critical responses

3. FAQ-first approach:
   - 90% of questions are common FAQs
   - FAQ answers are instant
   - AI only needed for 10% unusual queries

4. Batch processing:
   - Test with multiple queries
   - Watch model loading times
   - First query loads model (~1-2 seconds)
   - Subsequent queries faster

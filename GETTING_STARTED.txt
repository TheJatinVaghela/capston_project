================================================================================
TROUBLESHOOTING
================================================================================

Problem: Backend doesn't start / "Connection refused"
Solution: 
- Make sure you ran: pip install -r requirements.txt
- Try: pip install --upgrade pip
- Restart Command Prompt
- Try again: python app.py

Problem: Frontend shows error "Backend not responding"
Solution:
- Verify backend window shows "Server running..."
- Check the server is on http://127.0.0.1:5000
- Close and reopen frontend in browser
- Try different browser (Chrome, Firefox)

Problem: "ModuleNotFoundError: No module named 'flask'"
Solution:
- Make sure you're in backend folder: cd customer-service-chatbot\backend
- Run: pip install -r requirements.txt again
- Wait for it to complete

Problem: Python not recognized
Solution:
- Reinstall Python from python.org
- ⚠️  Check "Add Python to PATH" checkbox
- Restart Command Prompt/PowerShell after installing

Problem: Frontend loads but nothing happens
Solution:
- Open browser console: Press F12
- Look for error messages
- Try refreshing: Ctrl+F5 (hard refresh)
- Make sure backend server is running

================================================================================
HOW THE CHATBOT WORKS
================================================================================

When you type a message:

1. Your message goes to backend API
2. NLP pipeline processes it:
   - Converts to lowercase
   - Removes punctuation
   - Breaks into tokens (words)
   - Removes common words (stopwords)
   - Normalizes to base form (lemmatization)
3. Chatbot matches processed text against intent patterns
4. Calculates confidence score
5. Returns best matching response
6. If no good match, returns fallback response
7. Message logged to chat_logs.json
